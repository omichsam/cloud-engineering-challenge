## Part 4 – Basic Research Task

1. **What is cloud computing?**  
   Delivering computing services (servers, storage, databases, networking, software) over the internet ("the cloud") for flexible, pay-as-you-go use.

2. **What is DevOps?**  
   A set of practices that combines software development (Dev) and IT operations (Ops) to shorten development cycles and deliver high-quality software continuously.

3. **Difference between Docker and Kubernetes?**  
   - **Docker** packages applications into lightweight containers.  
   - **Kubernetes** orchestrates and manages multiple containers across clusters (scaling, deployment, networking).

4. **Why are Linux skills important in cloud engineering?**  
   Most cloud servers run on Linux; cloud engineers use Linux commands daily for file management, permissions, process control, and automating tasks.

## Part 5 – Problem Solving Question

**Question:** A cloud server becomes inaccessible. What 3 things would you check first?

1. **Security group / firewall rules** – ensure SSH (port 22) or relevant ports are open.
2. **Server status** – check if the instance is running (not stopped/terminated) and has high CPU/memory load.
3. **Network connectivity** – verify the public IP, route tables, and internet gateway (if public-facing).
