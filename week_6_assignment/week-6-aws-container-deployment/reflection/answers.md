# Reflection answers
## 1
EC2 gives direct control over the operating system and Docker, but the learner patches the host, monitors it, and plans capacity. ECS Fargate removes host management and scales tasks through a service desired count. EC2 can be cheaper for a continuously running small lab, while Fargate charges for task resources and RDS adds managed-database cost. Fargate and RDS improve repeatability and availability options, but require more IAM, VPC, and security-group configuration. EC2 is simpler to understand initially; Fargate is closer to a managed production operating model.
## 2
RDS provides managed backups, patching, monitoring, storage options, and recovery features that a student must build and maintain when MySQL runs in a container. A container volume can persist data, but it does not automatically provide multi-AZ availability, automated backups, or database maintenance. RDS also separates application deployment from database lifecycle. It costs more than a local container, so a Docker MySQL container remains useful for development and a small EC2 lab.
## 3
Fargate avoids managing worker servers, lets ECS place and restart tasks, and scales desired task counts without manually provisioning instances. It integrates with IAM, VPC security groups, and CloudWatch logs. These benefits reduce operational work while preserving container packaging.
## 4
EC2 is a virtual server. ECS is AWS's container scheduler. Fargate is the serverless compute option for ECS tasks. RDS is a managed relational database. Security groups are stateful network firewalls attached to AWS resources. Docker packages software into images and runs containers. A Docker network gives containers private DNS and connectivity on one host. Together these services separate application runtime, scheduling, data management, and network access.
## 5
In the EC2 design, PHP and MySQL share a user-defined Docker network and PHP uses `task-tracker-mysql:3306`. In the ECS design, PHP runs in a Fargate task and uses the DNS endpoint generated by RDS. Environment variables provide the host, port, database, username, and password. The EC2 network or VPC security groups permit only required traffic, and neither design should use localhost for a separate database.
