# Cloud Engineering Challenge

## Coursework progress

This repository now covers the complete progression from Linux and Git foundations through Bash automation, Docker, Kubernetes, and AWS container deployment.

| Week | Focus | Main deliverables |
|---|---|---|
| 1 | Linux and DevOps foundations | Linux scenarios, DevOps walkthrough, shell practice, screenshots |
| 2 | Git collaboration | Branching, merges, conflicts, rebase, hotfixes, tags, recovery |
| 3 | Bash automation | Watchdog, deployment/rollback, monitoring, onboarding, EC2 setup |
| 4 | Docker containerization | Six Docker/Compose applications, tests, networks, volumes, READMEs |
| 5 | Kubernetes orchestration | PHP/MySQL/phpMyAdmin Minikube lab, manifests, PVC, study guide |
| 6 | AWS container deployment | EC2 Docker path, ECS Fargate + RDS path, scripts, reflection |
